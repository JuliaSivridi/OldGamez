# oldgamez_bot

Единый Telegram-бот для мини-игр.

## Что уже заложено

- один бот и одна точка входа
- Docker Compose для бота и PostgreSQL
- SQLAlchemy-модели для пользователей, игровых сессий и статистики
- структура проекта, где каждая игра живет в своем модуле
- первая перенесенная игра: `tic-tac-toe`
- простой HTTP healthcheck для хостингов, которые ждут ответ на порту

## Запуск в Docker

1. Скопировать `.env.example` в `.env`
2. Указать `BOT_TOKEN`
3. При необходимости указать `PORT` в `.env`
4. Запустить:

```bash
docker compose up --build
```

## Почему PostgreSQL в Docker

PostgreSQL не нужно устанавливать на сервер вручную, если на сервере есть Docker. База поднимается отдельным контейнером через `docker compose`.

## Идея архитектуры

- `app/main.py` - точка входа
- `app/handlers/` - команды и роутинг Telegram
- `app/games/` - отдельные игровые модули
- `app/services/` - бизнес-логика
- `app/db/` - модели и подключение к БД

## Почему хостинг мог убивать контейнер

Некоторые платформы ожидают, что приложение начнет отвечать по HTTP за 10-15 секунд.
Telegram-бот на polling сам по себе порт не открывает, поэтому платформа считает контейнер "неживым".
В этом проекте бот теперь поднимает простой healthcheck-сервер на `PORT` и параллельно работает через polling.
