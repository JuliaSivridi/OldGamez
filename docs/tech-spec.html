1. Overview

OldGamez is an async Telegram bot that consolidates 15 classic mini-games under one username. Key design decisions:

  • Three play modes — solo vs bot, private duel via invite link, group match with inline buttons
  • Unified gamification — XP, 7 AI-themed levels, per-game and cross-game win streaks, per-game and global leaderboards
  • Inline keyboard UI only — no reply keyboards; messages update in-place via edit_message_text, works cleanly in groups
  • Stateless handlers — all game state lives in game_sessions.state (PostgreSQL JSON); handlers can restart without losing games
  • Zero-copy deployment — Docker Compose with entrypoint.sh running alembic upgrade head then the bot

3. Architecture

Pattern

Handler → Service → ORM → PostgreSQL

No repository abstraction. Handler functions call service functions directly. Service functions open an async with SessionLocal() context, perform ORM operations, commit, and return domain objects or plain dicts.

Data-flow diagram

User taps button
       │
       ▼
 aiogram Dispatcher
 (NullGuardMiddleware — guards from_user / message nulls)
       │
       ▼
 Router (per-game or common)
 handler function
       │
       ├─► upsert_user()              → users table
       ├─► get / create session       → game_sessions table
       ├─► GameXxx.method()           → pure Python game logic (no I/O)
       ├─► update_session_state()     → UPDATE game_sessions
       ├─► finish_session()           → UPDATE game_sessions status=finished
       ├─► record_game_result()       → UPSERT game_stats + UPDATE users.xp + streaks
       └─► message.edit_text()        → Telegram API

Write path (solo game move)

  1. User taps inline button; aiogram delivers CallbackQuery
  2. NullGuardMiddleware verifies from_user and message are not None
  3. Handler calls validate_session(callback, session_id) — loads user + lang pack, verifies ownership and status=active
  4. Handler calls game logic method (pure Python, returns new state dict)
  5. Handler calls update_session_state(session_id, new_state, turn_user_id) → SQLAlchemy UPDATE
  6. If game over: finish_session() + record_game_result() → updates game_stats, user.xp, streaks
  7. Handler calls message.edit_text(rendered_board, reply_markup=keyboard)

Error handling

  • safe_edit() wraps edit_text() and swallows TelegramBadRequest: message is not modified
  • All other Telegram errors propagate to aiogram's default handler (logs and continues)
  • Feedback send/forward wrapped in try/except — best-effort delivery
  • Cleanup loop catches and logs exceptions per iteration

7. First-Launch Setup

No authentication. Every Telegram user who sends a message is automatically registered.

  1. User sends /start
  2. upsert_user(tg_user) — SELECT WHERE telegram_user_id = ?
  3. If not found: INSERT new User with Telegram-provided name/username/language
  4. If found: UPDATE username/first_name/last_name; preserve language_code if language_manual is set in settings
  5. Language pack loaded: Telegram language code normalised to en/fi/ru (default en)
  6. Greeting variant selected by comparing settings["last_seen_at"] with now:
    — No last_seen_at + created within 30 s → hi-new
    — No last_seen_at + older user → hi-return
    — Same calendar day → hi-today
    — Away ≥ 14 days → hi-away
    — Otherwise → hi-return
  7. Main menu sent; last_seen_at updated in user.settings

8. Game Session Flows

Solo game

  1. User selects game → handler calls new_game_state()
  2. create_solo_session(): abandons any existing active solo session for same user+game; inserts new session status=active
  3. Board rendered and sent as new message
  4. Each move: validate_session() → game logic → update_session_state()
  5. Game over: finish_session() + record_game_result() → XP + streak update

Private duel

  1. Host taps "Duel" → create_private_duel_invite(): inserts status=pending, join_code=secrets.token_hex(4), invite_expires_at=now()+7d
  2. Bot sends message with Telegram share button wrapping deep link
  3. Deep link: https://t.me/{BOT_USERNAME}?start=join_{join_code}
  4. Guest taps link → /start join_{code} → handle_private_duel_start() → game-specific join_private_duel()
  5. activate_private_duel_session(): adds guest as SessionPlayer(seat_no=2); status=active; join_code=None
  6. Both players get separate messages; message_ids stored in state for broadcast_private_duel_update()

Group match

  1. User sends command in group → create_group_match_session(): status=pending, no join_code
  2. Bot posts "waiting" message with inline "Join" button
  3. Second member taps Join → activate_group_match_session(): adds guest; status=active
  4. Single message edited in-place as game progresses; XP and streaks recorded for both at finish

Cleanup TTLs

  • Private duel invites: expire after 7 days if not joined
  • Pending group matches: expire after 7 days if not joined
  • Expired + abandoned sessions: hard-deleted weekly

Streak logic

Win streaks use the user's stored IANA timezone. Streak continues if last_win_date == today - 1 day; resets to 1 if gap > 1 day; same-day wins are idempotent (no double count). Per-game and cross-game streaks are updated on every record_game_result() win.

11. Interaction Surfaces

Main menu

  • Private: two pages of games; compact user info line (Name | Level icon ⚡XP | rank | streak); page switch via menu:page:{n}
  • Group: single page; only games with group_row != None; info line suppressed
  • Greeting variants driven by last_seen_at: hi-new / hi-today / hi-return / hi-away

Game menu

  • Shows: icon + name + current setting + per-game streak (private only)
  • Buttons: Play / Duel / Group / Size-Cmplx / 📊 Stats / 🏆 Top / ❓ Help / ⬅ Back
  • Group chat: only "Group" button shown; no Play or Duel buttons

Profile (private only)

Keyboard layout: adjust(3, 2, 2, 1) = Streaks/Stats/Rankings | XP/Name | Lang/Tz | Back

  • profile:streaks — per-game streak table
  • profile:stats — per-game played/W/L/D table
  • profile:rankings — global rank + all played games with positions
  • profile:xp — level reference table + note explaining XP vs rank
  • profile:name — display name format; anon mode purchasable for 5 ⭐
  • profile:lang — language picker (🇬🇧 / 🇫🇮 / 🇷🇺)
  • profile:tz — timezone picker (region → city, 2-column layout)

Donate

Amounts: 50 / 100 / 200 / 500 Telegram Stars (currency XTR, provider_token=""). Explanation text shown before amount selection.

Feedback

Private chat only. FSM state FeedbackStates.waiting_for_text. Saved to DB; if FEEDBACK_CHAT_ID configured: sends formatted notification + forwards the original message to that chat.

Admin Dashboard

Protected by DASHBOARD_TOKEN query parameter. Self-contained HTML with: running games (hidden game state: mine field, bot board, secret), game stats summary, user list, feedback inbox with delete buttons.

14. Background Tasks

cleanup_loop() — asyncio.create_task

loop:
  sleep 24h
  expire_stale_private_duels()
    -- SET status=expired WHERE mode=duel_private
    -- AND status=pending AND invite_expires_at < now()
  expire_stale_group_matches()
    -- SET status=expired WHERE mode=group_match
    -- AND status=pending AND created_at < now()-7d
  days_since_deletion += 1
  if days_since_deletion >= 7:
    delete_stale_sessions()
      -- DELETE WHERE status IN (expired, abandoned)
    days_since_deletion = 0
Also runs once at startup (before polling begins) to catch sessions that expired while the bot was down.

15. i18n

Three language packs: en, fi, ru. Stored in app/i18n/languages.json, loaded once via lru_cache.

  • Keys with multiple variants (greetings) are stored as list[str]
  • pick(pack, key, **fmt) randomly selects one; filters out variants containing {name} if name is empty
  • Language selection persisted as user.settings["language_manual"] — survives Telegram profile language changes
  • Alphabet for Hangman/Wordle: LANGUAGE_LETTERS (en: a–z; fi: a–z+å,ä,ö; ru: а–я)
  • Supported languages: {"🇬🇧 English": "en", "🇫🇮 Suomi": "fi", "🇷🇺 Русский": "ru"}

17. Key Algorithms

TicTacToe — smart bot move (get_smart_move)

free_positions = all empty cells

for each pos in free_positions:
  if bot wins by placing here → return pos immediately

  if user wins by placing here → add to "block" list
  if bot gets (win_length-1) in a row → add to "nice" list
  if user gets (win_length-1) in a row → add to "threat" list

priority: block → nice → threat → center → corners → random

# win_length = board_size for 3×3/4×4; board_size-1 for 5×5+

Bulls and Cows / Mastermind scoring (score_guess)

bulls = count(positions where secret[i] == guess[i])
secret_rest = secret digits that didn't match positionally
guess_rest  = guess digits that didn't match positionally
cows = sum(min(secret_rest.count(x), guess_rest.count(x))
           for x in set(guess_rest))
return bulls, cows

Win ratio bar (_win_ratio_bar) — Largest Remainder Method

raw[i]     = count[i] / total * 10
floored[i] = floor(raw[i])
remainder  = 10 - sum(floored)

sort segments by (raw[i] - floored[i]) descending
assign 1 extra slot to each of top `remainder` segments

render: win_icon × w_slots | draw_icon × d_slots | loss_icon × l_slots
# always exactly 10 icons total

Blackjack soft-17 detection (is_soft)

if no ace in hand → return False
non_ace_sum = sum of non-ace card values
ace_count = count of aces
return non_ace_sum + 11 + (ace_count - 1) ≤ 21
  # True = at least one ace can be counted as 11 without busting

Dealer uses H17 rule: hits on soft 17, stands on hard 17 and above.

XP level detection (get_level)

current = LEVELS[0]
for lvl in LEVELS:
  if xp >= lvl.xp_required:
    current = lvl
return current   # last level whose threshold is ≤ xp

Win streak update (_compute_streak)

if last_win_date == today:
  return unchanged          # idempotent

if last_win_date == today - 1 day:
  new_current = current + 1  # streak continues
else:
  new_current = 1            # streak broken or first win

return today, new_current, max(best, new_current)

Leaderboard ranking (computed at query time)

user_score[uid] = sum(
  wins * GAME_VARIANT_POINTS[game][variant]
  for each GameStat row with wins > 0
)
my_pos = count(scores > my_score) + 1
# No stored rank column — always recomputed fresh
